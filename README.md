# Isaac's Law Cram Quiz

Mobile-friendly multiple choice quiz for ATI Year 1 Business Law NI exam (Thu 21 May 2026).

## Live URL

Once GitHub Pages is enabled: **https://webweaverltd.github.io/law-quiz/**

## Topics covered (60 questions)

- Employment Law (14)
- Data Protection (10)
- Business Organisations (10)
- Company Directors (10)
- Auditors and Company Secretary (9)
- Key Acts recognition (7)

## Features

- Mobile-first dark theme (gym-friendly)
- Filter by topic
- Instant feedback with explanations
- Live score / streak tracker
- Works offline once loaded
- Reshuffle to drill repeatedly

## How to enable GitHub Pages

1. Go to repo Settings tab
2. Click "Pages" in left sidebar
3. Under "Build and deployment", set Source to "Deploy from a branch"
4. Set Branch to `main`, Folder to `/ (root)`
5. Click Save
6. Wait ~1 minute, then visit https://webweaverltd.github.io/law-quiz/

Bookmark on phone for instant access.
